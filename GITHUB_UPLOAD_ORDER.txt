1. Create a PUBLIC GitHub repository named: amazon-deals
2. Upload the complete deals/ folder (001.json ... 055.json + manifest.json).
3. Commit to main.
4. Edit config.js:
   window.GITHUB_REPO = 'YOUR_USERNAME/amazon-deals';
   window.GITHUB_REF = 'main';
   window.AMAZON_AFFILIATE_TAG = 'YOUR_REAL_TAG-21';
5. Upload index.html, styles.css, config.js, app.js, deal-loader.js to your website.
6. Test the jsDelivr manifest URL.
7. Open the product grid and click Buy Now; the URL should contain ?tag=YOUR_REAL_TAG-21
